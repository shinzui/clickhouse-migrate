## Required behavior and artifacts

Every candidate runs all thirteen groups, serially: transport, completion, ledger,
exclusive, runner, repair, boundaries, survivors, adoption, consumer, cli, example,
and remediation. Both Nix-built suite/driver/example and extracted sibling source
archives run the same complete matrix. The source archives additionally pass Cabal
metadata checks, three pure suites and Haddocks. Missing candidate prerequisites
fail the run; no group or artifact variant silently skips a candidate.

The initial source archives passed all 26 candidate/group combinations. A subsequent
Nix run exposed a fixture startup failure before the server started: choosing a free
port on the macOS client did not reserve that port on the Docker VM. Retained Docker
diagnostics identified `address already in use`. The final fixture lets Docker
allocate both published ports and keeps their container network namespace alive
while restarting only ClickHouse. A direct restart proof now preserves both endpoints,
server UUID and committed data. This is a fixture correction, not a server retry or
a relaxation of admission. Failed startup remains a failed case and diagnostics are
preserved under the owned temporary root.

The final Nix suite/driver/example passed all 26 candidate/group combinations after
the port-lifecycle fix. The final extracted-source variant also passed all 26 combinations, along with
seven metadata checks, three pure suites and Haddocks. [The receipt](2026-11-02-altinity.json)
retains archive hashes, Nix derivation identifiers and implementation hashes. The
policy, fixture and suite-entry bytes match the pinned implementation revision
`00afa9fa1038f2b90e7bc5f041ac1b56649b639f`; subsequent changes only record qualification
metadata and documentation. Core
production closure checks also pass: optional packages, container/process harnesses
and private drivers are excluded (330 Nix runtime references). Workflow syntax,
formatting and strict user-documentation validation pass. CI now declares an isolated
Colima context and exact server image on an ARM Darwin runner; no remote run is claimed. No source artifact has been published from this
working candidate.

## Reproduction

Resolve this source project with Mori. Pre-pull the exact digest into a fresh local
Docker context, then run from the project:

```bash
export CLICKHOUSE_MIGRATE_DOCKER_CONTEXT=<isolated-local-context>
nix develop -c just test-release-matrix
nix develop -c just qualify-distributions
nix build .#integration-tests .#internal-test-driver .#example --no-link --json
```

For the Nix variant, pass the three returned executable paths in
`CLICKHOUSE_MIGRATE_SUITE`, `CLICKHOUSE_MIGRATE_TEST_DRIVER` and
`CLICKHOUSE_MIGRATE_EXAMPLE` to `scripts/test-release-matrix.py`. Execute the installed
binaries; do not inspect or traverse the Nix store. Their installed data files select
the same candidate and fixture. The release lock coordinates only workstation test
fixtures and supplies no administrative exclusion/drain evidence.
